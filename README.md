# AI Agent Memory for Changing Knowledge

Coursework on how an AI agent can keep track of facts that change over time. The project focuses on where a fact came from, when it applies, and what happens when its source retracts it.

## Research question

How should an agent answer when it has several versions of a fact? For example, a team might first announce a Friday release, move it to Monday, and later retract the announcement. An agent needs the history and sources to answer both what was announced earlier and what is confirmed now.

## Status

The repository currently contains the coursework topic. The implementation and evaluation are pending.
